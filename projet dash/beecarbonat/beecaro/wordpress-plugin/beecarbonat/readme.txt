Intégrez la plateforme BeeCarbonat Enterprise (ESG, CAFM, Smart City, Gestion Énergétique, Marché Carbone) directement dans votre site WordPress.

== Description ==

BeeCarbonat Enterprise est la plateforme de référence pour la gestion technique des bâtiments (CAFM), le suivi ESG, l'efficacité énergétique en temps réel et le marché des crédits carbone.

Cette extension WordPress officielle vous permet de :
* Intégrer l'ensemble ou des modules spécifiques de BeeCarbonat sur vos pages publiques via le shortcode `[beecarbonat]`.
* Accéder directement au cockpit complet dans votre panneau d'administration WordPress (`wp-admin > BeeCarbonat OS`).
* Conserver le style cyberpunk moderne et fluide (mode sombre immersif ou clair moderne).
* Profiter du mode plein écran interactif et de l'adaptation automatique mobile et desktop.

== Installation ==

1. Téléversez le dossier `beecarbonat` dans le répertoire `/wp-content/plugins/` (ou téléversez le fichier `.zip` via Extensions > Ajouter > Téléverser).
2. Activez l'extension via le menu 'Extensions' dans WordPress.
3. Rendez-vous dans 'BeeCarbonat OS > Réglages' pour renseigner l'URL de votre application si nécessaire.
4. Insérez le code court `[beecarbonat]` dans la page ou l'article de votre choix.

== Shortcodes Disponibles ==

* `[beecarbonat]` : Affichage par défaut complet avec bandeau et bouton plein écran.
* `[beecarbonat view="carbonmarket"]` : Affichage direct du marché carbone.
* `[beecarbonat view="cmms"]` : Affichage de la gestion technique de maintenance assistée par ordinateur.
* `[beecarbonat height="900px" theme="dark"]` : Personnalisation de la hauteur et du thème.
